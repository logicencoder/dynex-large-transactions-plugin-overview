# Dynex Large Transactions

![Dynex Large Transactions workspace](assets/live-transactions-expanded.png)

Large transfers can disappear into a busy chain feed. Dynex Large Transactions gives visitors a focused view of those movements, with summary figures, address search and transaction details in a WordPress dashboard.

## Tech stack

| Layer | Technologies |
|---|---|
| Application | PHP, WordPress |
| Supporting technologies | HTML, CSS, JavaScript; Dynex |

## Follow the relevant transfers

The feed keeps large movements together instead of mixing them with unrelated chain activity. Expand entries when more context is needed, or keep the view compact for scanning. Transaction references support further investigation.

![Dynex Large Transactions — Follow the relevant transfers](assets/live-transactions-collapsed.png)

## Read the broader context

Summary statistics help place the current feed in perspective. Time and activity information support deciding whether a movement deserves closer attention. The view presents observations without assigning an unsupported explanation to the transfer.

![Dynex Large Transactions — Read the broader context](assets/live-statistics-panel.png)

## Search by address

Address search offers a more direct route when the visitor is investigating a particular participant. It narrows the task from scanning a general feed to checking relevant activity. Results remain part of the same dashboard experience.

![Dynex Large Transactions — Search by address](assets/live-address-search.png)

## Publish and maintain the dashboard

The site owner can embed the view in WordPress and use administrator status and settings areas to maintain it. This keeps the public feed and operational checks within the same product.

![Dynex Large Transactions — Publish and maintain the dashboard](assets/admin-dashboard.png)

![Dynex Large Transactions — Publish and maintain the dashboard](assets/admin-settings.png)
